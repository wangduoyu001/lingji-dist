# 灵机 · Windows 安装包分发

本仓库**只存放对外分发的安装产物**，不包含灵机源代码。源代码仓库保持私有。

## 给使用者：怎么安装

**第 1 步**：下载 `install_lingji.bat`

**第 2 步**：双击运行

就这两步。脚本会自动下载安装包、解压、安装本地大模型、拉起灵机后端，并自动把灵机 MCP 注册到你电脑上已安装的 AI 工具（Claude Code / Codex CLI / WorkBuddy / Gemini CLI）。

如果同目录下已经手动下载了 `lingji-windows-x64.zip`，脚本会优先使用本地包，不再联网下载。

## 需要注意

- 安装目录默认选**非系统盘**（E 盘 / D 盘），且需要至少 50 GB 可用空间——本地模型占用较大。
- 安装过程会调用 [Ollama](https://ollama.com/) 下载 3 个模型（约 6 GB）：
  - `qwen3:8b`（对话与推理）
  - `qwen3-embedding:0.6b`（记忆向量化）
  - `nomic-embed-text`（文本嵌入）
  如果你机器上已经有这三个模型，会自动复用，不会重复下载。
- 全程联网，除下载安装包和模型外不向任何第三方上传数据。灵机所有记忆数据都保存在本机安装目录内。

## 卸载

在同一个 bat 里加 `--uninstall` 参数运行即可：

```bat
install_lingji.bat --uninstall
```

脚本会先列出将被删除的内容并要求你输入「卸载」二字确认，然后只删除灵机自己的目录和它独占的 3 个 Ollama 模型，**不会动你电脑上的其他任何文件**。

## 常用参数

| 参数 | 说明 |
|---|---|
| `--root <目录>` | 指定安装目录（默认自动选非系统盘） |
| `--url <zip地址>` | 指定安装包下载地址 |
| `--no-link` | 安装但跳过自动 MCP 注册 |
| `--uninstall` | 一键卸载 |
| `--help` | 显示帮助 |

## 完整性校验

`SHA256SUMS` 列出包内每个文件的 SHA-256，可用于校验下载是否完整。
